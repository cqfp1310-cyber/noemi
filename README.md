# 🌹 Dedica Musicale per Noemi

Una pagina web romantica e curata nei minimi dettagli per una dedica musicale speciale, completa di animazione di petali di rosa cadenti, lettore musicale interattivo e messaggi personalizzati.

## 🚀 Come caricarla su GitHub e pubblicarla con GitHub Pages

1. **Crea un nuovo repository su GitHub** (es. `dedica-noemi`).
2. Carica questi tre file nella root del repository:
   - `index.html`
   - `style.css`
   - `script.js`
3. Vai nelle **Settings** del repository su GitHub.
4. Clicca sulla scheda **Pages** nella barra laterale sinistra.
5. Sotto **Build and deployment**, seleziona il branch `main` (o `master`) e `/ (root)` come cartella, poi clicca su **Save**.
6. Entro pochi minuti GitHub pubblicherà il tuo sito all'indirizzo indicato (es. `https://tuonome.github.io/dedica-noemi/`).
